# VNC desktop

**More → Desktop (VNC)** starts a VNC server inside the chroot and lets you open the Linux desktop, which is where heavy GUI / launch-only tools run.

## Requirements
- The environment (rootfs) must be installed — see **Installer & rootfs**.
- Chroot requires uid 0 (root or Sui) — see **Privilege modes**.

## Display
You can set the VNC display in **Settings → VNC display**. Start the server from the Desktop screen, then connect with your VNC viewer.
