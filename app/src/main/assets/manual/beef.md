# BeEF-XSS control panel

**More → BeEF-XSS control panel** is an in-app front end for BeEF (the Browser Exploitation Framework), which runs inside VictorSuite.

## What you can do
- **Start / stop** BeEF in VictorSuite.
- See **hooked browsers** in a dashboard.
- Run **modules** against a hooked browser.

## Authorized use only
BeEF hooks browsers — use it only within an authorized engagement, against targets that consented and are in scope. The panel carries the authorized-use banner.
