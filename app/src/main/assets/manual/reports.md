# Reports (Markdown & PDF)

Build a report for an engagement from **Engage → an engagement → Report**, then export from the export screen.

## What's in a report
1. The legal notice, scope and authorization (with a warning if authorization is missing)
2. A severity summary
3. Tools and workflows run, with timestamps
4. Findings grouped by severity (CVSS 3.1 where scored)

## Export formats
- **Markdown** — plain `.md`
- **PDF** — a branded PDF with the VictorDrax header

Both are written through the Android system save dialog (SAF), and you can **share** them directly.
