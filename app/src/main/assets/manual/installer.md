# Installer & rootfs

**More → Install environment** downloads and extracts the ANDRAX rootfs into your install path.

## Install path
Set the path in **Settings → Install path** (default `/data/local/andrax`). You must uninstall before changing it. Paths are validated for safety.

## Steps
1. Set a privilege mode that can chroot (root or Sui) — see **Privilege modes**.
2. Download the rootfs.
3. Extract it to the install path.
4. From there you can use the terminal, tools, and the VNC desktop.

The download/extract and chroot steps need a real device with root (or Sui) to complete.
