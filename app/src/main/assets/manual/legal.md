# Legal & authorization

VictorDrax is for **AUTHORIZED security testing only**. Use it only on systems you own or for which you have explicit written permission to test. Unauthorized access to computer systems is illegal. You alone are responsible for how you use it.

## The first-run notice
When you first open the app you must tick *"I will only test systems I own or have written permission to test"* and accept the legal notice. You can re-show it later from **Settings → Legal → Reset acceptance**.

## Why scope matters
Every tool run, scan, workflow and schedule is gated. A command can only run against a target that is inside an authorized engagement's scope. This is enforced in code, not just in documentation — see **Engagements & scope**.
