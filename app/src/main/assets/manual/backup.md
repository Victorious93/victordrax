# Backup & restore

**More → Backup & restore** exports and imports an **encrypted** backup of your VictorDrax data (engagements, findings, settings).

## Export
Choose export, set a passphrase, and save the encrypted file through the system save dialog. Keep the passphrase safe — without it the backup cannot be restored.

## Restore
Pick a previously exported backup file and enter its passphrase to import it. No secrets are stored in the app or the repo.
