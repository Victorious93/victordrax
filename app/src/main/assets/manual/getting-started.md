# Getting started

VictorDrax is an ANDRAX-NG-based mobile penetration-testing platform for **authorized testing only**. It gives you a neon Compose UI over a Linux (ANDRAX) environment, with tool launchers, engagement tracking, findings, reports and automation.

## First run
On first launch you must read the legal notice and confirm that you will only test systems you own or have written permission to test. You cannot continue until you accept.

## Moving around
The bottom bar (or side rail on wide screens) has five destinations:

- **Home** — the dashboard with status and quick tiles.
- **Tools** — the Kali tool library and GUI forms.
- **Terminal** — hands commands to the VictorSuite terminal.
- **Engage** — your engagements, scope, findings and reports.
- **More** — everything else: workflows, scheduler, packages, install, desktop, backup, BeEF, settings, about and this manual.

## Suggested first steps
1. Read **Legal & authorization**.
2. Create an **engagement** and record who authorized it plus its in-scope targets.
3. Set up your **privilege mode** (root, Shizuku, or none).
4. Install the environment from **Installer & rootfs** if you have not already.
